# FM-1 Again SMK-37

[FM-1 Again](https://github.com/PolarPatch/FM-1-Again) by PolarPatch for the **M-VAVE SMK-37** (Pro, Elite and
MKE-P37): warm, emotional, rhythmic electronic music, made again, on 37 keys, 16 pads, eight knobs, four faders and two
wheels. Grooves, chords pumping under the kick, chopped voices, builds and drops.

**NEW! Plays via Wi-Fi to Ableton Note!** The same as FM-1 Again 1.0.7 on the FM-1:

- **Ableton Link over Wi-Fi:** tempo, beat and start / stop shared with Ableton Note, Live and other Link apps, on
  your home network (AUTO) or with the SMK-37 as its own access point (AP).
- **The notes to a phone:** over Bluetooth MIDI, or over Wi-Fi (NETMIDI: RTP-MIDI, the phone's Network Session).
- The LINK page: GLOBE (GLO) a fifth time. See FM-1 Again's [manual](app/docs/MANUAL.md).

## Install

[The latest release](https://github.com/PolarPatch/FM-1-Again-SMK-37/releases/latest): `again-smk37-1.0.7.fwsc` for
the SMK-37 Pro, `again-smk37-mke-1.0.7.fwsc` for the MKE-P37 (the Elite later). Install it as other SMK-37 firmwares
(the Firmware Hub). **An early version:** the FM-1's controls on the SMK-37 (the 27 middle keys, the buttons and the
knobs); the pads, faders and wheels come next. No screensaver film on the SMK-37 yet.

## The FM-1's buttons on the SMK-37

FM-1 Again's [manual](app/docs/MANUAL.md) names the FM-1's buttons. On the SMK-37 they are:

| FM-1 | SMK-37 |
|---|---|
| SEL | SCALE |
| ENV | CHORD |
| LFO | NOTE REPEAT |
| EDIT | PARA |
| GLO | GLOBE |
| HOME | PATCH |
| SAVE | BT |
| PLAY | SEQ PLAY |
| REC | SEQ REC |

FX, ARP, SEQ and OCTAVE -/+ are the same. The knobs: K1..K4 as on the FM-1, K6 SELECT, K7 ALGORITHM, K8 PRESETS,
K5 the volume (MASTER). Settings are kept when you press SAVE (BT): Wi-Fi, Link and NETMIDI too.
